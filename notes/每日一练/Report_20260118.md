## 一、HTML & CSS (1-10)

### 1. HTML 语义化的意义和好处

**高频公司**: 百度、网易、京东
**考察点**: 代码可读性、SEO、无障碍访问 (Accessibility)。
**参考答案**:

- 意义：使用正确的标签描述正确的内容（如 `<header>`, `<main>`, `<footer>`, `<section>`）。
- 好处：
  - 提升 SEO：搜索引擎能更好地理解页面结构。
  - 增强无障碍性：屏幕阅读器能正确解析。
  - 提高开发维护效率：代码结构清晰。

### 2. 标准盒模型与 IE 盒模型的区别

**高频公司**: 全部
**参考答案**:

- 标准盒模型 (`content-box`)：`width` = `content`。总宽度 = `width` + `padding` + `border` + `margin`。
- IE 盒模型 (`border-box`)：`width` = `content` + `padding` + `border`。
- 切换：`box-sizing: border-box;`。

### 3. BFC (块级格式化上下文)

**高频公司**: 字节跳动、美团
**参考答案**:

- 原理：内部盒子垂直排列，不影响外部。
- 触发：`overflow: hidden`, `display: inline-block`, `position: absolute/fixed`。
- 应用：防止外边距重叠、清除浮动（解决高度塌陷）。

### 4. Flex 布局与 Grid 布局

**高频公司**: 阿里、快手
**参考答案**:

- Flex：一维布局（行或列），适合简单线性结构。
- Grid：二维布局（行和列），适合复杂网格结构。

### 5. 水平垂直居中实现

**高频公司**: 全部
**参考答案**:

1. Flex: `justify-content: center; align-items: center;`
2. Grid: `place-items: center;`
3. Absolute: `top: 50%; left: 50%; transform: translate(-50%, -50%);`

### 6. CSS 选择器优先级

**高频公司**: 全部
**参考答案**:
`!important` > 内联 (1000) > ID (100) > 类/伪类/属性 (10) > 标签/伪元素 (1) > 继承/通配符。

### 7. Position 属性及其 Sticky

**高频公司**: 全部
**参考答案**:

- `static`, `relative`, `absolute`, `fixed`, `sticky`。
- `sticky`：基于滚动位置切换相对和固定定位，常用于吸顶效果。

### 8. HTML/CSS 性能优化

**参考答案**:

- CSS 放置头部，JS 放置尾部或使用 `defer/async`。
- 减少 CSS 选择器层级。
- 使用 `critical content` 提取。
- 避免使用 CSS 表达式。

### 9. Canvas vs SVG

**高频公司**: 腾讯 (可视化方向)
**参考答案**:

- Canvas：位图，脚本驱动，适合高性能渲染（游戏）。
- SVG：矢量图，XML 描述，适合小图标、图表，支持 DOM 事件。

### 10. rem, em, vh, vw 单别

**参考答案**:

- `rem`：相对于根元素 (`<html>`) 字体大小。
- `em`：相对于父元素字体大小。
- `vh/vw`：相对于视口高度/宽度的 1%。

## 二、JavaScript (11-20)

### 11. 数据类型及其区别

**高频公司**: 全部
**参考答案**:

- 原始：`string`, `number`, `boolean`, `undefined`, `null`, `symbol`, `bigint` (值类型，存栈)。
- 引用：`Object`, `Array`, `Function` (存堆，栈存引用)。

### 12. 原型链与原型继承

**高频公司**: 字节跳动、阿里
**参考答案**:
通过 `__proto__` 属性将对象连接起来。查找属性时由近及远。ES6 `class` 仍基于此实现。

### 13. 闭包 (Closure)

**高频公司**: 全部
**参考答案**:
函数可以访问其定义时的词法作用域。用途：封装私有变量。风险：不当使用导致内存泄露（引用无法回收）。

### 14. 事件循环 (Event Loop)

**高频公司**: 字节跳动、拼多多
**参考答案**:
同步任务 -> 微任务 (Promise.then) -> 宏任务 (setTimeout)。每一轮宏任务执行前会清空微任务队列。

### 15. call, apply, bind

**参考答案**:

- `call/apply`：立即调用，改变 `this`。`apply` 传数组。
- `bind`：返回新函数，不立即调用。

### 16. async/await 原理

**高频公司**: 小米、快手
**参考答案**:
Generator 生成器与 Promise 的语法糖。内部自动执行 Generator。

### 17. 深拷贝 vs 浅拷贝

**参考答案**:

- 浅拷贝：只拷贝一层引用（`Object.assign`）。
- 深拷贝：递归拷贝所有层级（JSON 序列化或递归递归）。

### 18. JavaScript 垃圾回收

**参考答案**:

- 标记清除（Mark-and-Sweep）：主要算法。
- 引用计数（Reference Counting）：循环引用会导致泄露。

### 19. Promise 状态与回调地狱

**参考答案**:

- `pending`, `fulfilled`, `rejected`。
- 解决：通过链式调用或同步写法 (`await`) 避免嵌套。

### 20. Set, Map, WeakSet, WeakMap

**参考答案**:

- `Map`：支持任何类型作为 Key。
- `WeakMap`：Key 必须是对象，弱引用，利于垃圾回收。

## 三、框架与工程化 (21-30)

### 21. Vue 2 vs Vue 3

**高频公司**: 美团、滴滴
**参考答案**:

- 响应式：`Object.defineProperty` -> `Proxy`。
- API：Options API -> Composition API。
- 动能：Fragment, Teleport, Suspense。

### 22. Vue 组件通信

**参考答案**:
`props`, `emit`, `provide/inject`, `Vuex/Pinia`, `eventBus` (Vue3 移除)。

### 23. React 生命周期

**参考答案**:

- 挂载：`constructor`, `render`, `componentDidMount`。
- 更新：`shouldComponentUpdate`, `render`, `componentDidUpdate`。
- 卸载：`componentWillUnmount`。
- Hooks 对应：`useEffect`。

### 24. 状态管理流程 (Redux/Zustand)

**参考答案**:
Store 存储状态，Action 描述变化，Reducer 处理更新。驱动 UI 重新渲染。

### 25. Webpack 构建流程

**参考答案**:
初始化参数 -> 编译 -> 确定入口 -> 编译模块 (Loader) -> 输出资源 (Chunk) -> 写入文件系统。

### 26. 微前端

**参考答案**:
将大应用拆分为独立的小应用。方案：`qiankun` (基于 single-spa), `Module Federation`。

### 27. 前端性能优化

**参考答案**:

- 代码层面：懒加载、防抖节流。
- 网络层面：HTTP2, CDN, Gzip。
- 构建层面：Tree Shaking, 压缩。

### 28. 前端路由原理

**参考答案**:

- Hash：`hashchange` 事件，带 `#`。
- History：`pushState/replaceState` API，无 `#`，需后端支持。

### 29. URL 输入到显示全过程

**参考答案**:
DNS -> TCP -> HTTP -> 渲染树 -> 布局 -> 绘制 -> 显示。

### 30. 跨域解决方案

**参考答案**:

- CORS：服务端设置响应头。
- Nginx 反向代理。
- JSONP：利用 `<script>` 不受同源策略限制。
