## 一、JavaScript 核心基础 (1-8)

### 1. 闭包 (Closure) 的深度理解

**高频公司**: 字节跳动、京东、腾讯  
**考察点**:

- 概念: 函数与其词法环境的组合。
- 应用: 模拟私有变量、柯里化、防抖节流。
- 风险: 闭包导致的内存泄漏及如何通过设置为 `null` 解决。

**参考答案**:

```javascript
function closureExample() {
  let heavyData = new Array(1000).fill("data");
  return function () {
    console.log(heavyData.length);
  };
}
let fn = closureExample();
// fn 长期持有 heavyData，使用完建议 fn = null;
```
