## 一、JavaScript 核心基础 (1-10)

### 1. 事件循环 (Event Loop) 深度解析

**高频公司**: 字节跳动、腾讯、美团、哔哩哔哩  
**考察点**:

- 宏任务 (setTimeout, I/O) 与微任务 (Promise.then, nextTick) 的执行顺序。
- 浏览器 Event Loop 与 Node.js 11+ 后的模型差异。

**参考答案**:

```javascript
// 执行顺序示例
console.log("script start");
setTimeout(() => console.log("setTimeout"), 0);
Promise.resolve().then(() => console.log("promise1"));
console.log("script end");
// 输出: script start -> script end -> promise1 -> setTimeout
```

**高频公司**: 字节跳动、百度、腾讯

### 6. JS 精准数据类型判断

**高频公司**: 拼多多、京东  
**参考答案**:

### 7. 浮点数精度丢失 (0.1+0.2)

**高频公司**: 字节跳动
