## 一、JavaScript 核心基础 (1-7)

### 1. JavaScript 数据类型详解及类型判断

**高频公司**: 全部  
**考察点**:

- 基本类型: String, Number, Boolean, Null, Undefined, Symbol, BigInt
- 引用类型: Object (Array, Function, Date, RegExp, Map, Set)
- 判断方法:
  - `typeof`: 适用于基本类型，但 `typeof null === "object"` (历史遗留 bug)
  - `instanceof`: 检测原型链，适用于引用类型
  - `Object.prototype.toString.call()`: 最精准的类型判断方式

**参考答案**:

```javascript
// 最准确的类型判断
function getType(obj) {
  return Object.prototype.toString.call(obj).slice(8, -1).toLowerCase();
}
```

### 2. 闭包的原理、应用与内存泄漏

**高频公司**: 字节跳动、腾讯、阿里  
**考察点**:

- 闭包形成: 函数嵌套 + 内部函数引用外部变量
- 常见应用: 数据私有化、模块化、柯里化、防抖节流
- 内存泄漏风险: 长期持有不再需要的引用

**参考答案**:

```javascript
// 闭包应用示例：私有变量
function createCounter() {
  let count = 0; // 私有变量
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count,
  };
}
// count 无法从外部直接访问，只能通过方法操作
```

### 3. 原型链与继承机制

**高频公司**: 全部  
**考察点**:

- `__proto__` 与 `prototype` 的区别
- 原型链查找机制
- 继承方式: 原型链继承、构造函数继承、组合继承、寄生组合继承

**参考答案**:

- 每个对象都有 `__proto__` 指向其构造函数的 `prototype`
- 原型链顶端是 `Object.prototype.__proto__ === null`
- 推荐使用 ES6 `class` 语法糖实现继承

### 4. Event Loop (事件循环) 深度解析

**高频公司**: 字节跳动、美团、拼多多  
**考察点**:

- 宏任务 (MacroTask): setTimeout, setInterval, I/O
- 微任务 (MicroTask): Promise.then, MutationObserver, process.nextTick (Node.js)
- 执行顺序: 同步代码 → 微任务队列 → 宏任务队列

**参考答案**:

```javascript
console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");
// 输出顺序: 1 4 3 2
```

### 5. Promise 静态方法对比

**高频公司**: 京东、小米、滴滴  
**考察点**:

- `Promise.all`: 全部成功才成功
- `Promise.allSettled`: 等待所有完成，返回状态数组
- `Promise.race`: 第一个完成的结果
- `Promise.any`: 第一个成功的结果

**参考答案**:
| 方法 | 成功条件 | 失败条件 | 使用场景 |
|------|---------|---------|---------|
| all | 全部成功 | 任一失败 | 并行请求且都必须成功 |
| allSettled | - | - | 需要所有结果状态 |
| race | 任一完成 | - | 超时控制 |
| any | 任一成功 | 全部失败 | 容错降级 |

## 二、CSS 布局与视觉 (8-11)

### 8. CSS 盒模型详解

**高频公司**: 全部  
**考察点**:

- 标准盒模型: `box-sizing: content-box` (默认)
  - 宽度 = content
- IE 盒模型: `box-sizing: border-box`
  - 宽度 = content + padding + border

**参考答案**:
推荐全局设置 `* { box-sizing: border-box; }` 以避免尺寸计算混乱。

---

### 9. BFC (块级格式化上下文)

**高频公司**: 字节跳动、美团  
**考察点**:

- 触发条件: `overflow: hidden/auto`, `float`, `position: absolute/fixed`, `display: flex/grid`
- 解决问题: 清除浮动、避免外边距重叠、自适应两栏布局

**参考答案**:

```css
/* 清除浮动 */
.parent {
  overflow: hidden; /* 触发 BFC */
}
```

**考察点**:

### 11. innerHTML 与 innerText 的区别

**高频公司**: 小米、拼多多  
**考察点**:

- `innerHTML`: 解析 HTML 标签 (存在 XSS 风险)
- `innerText`: 仅处理文本内容，忽略 HTML
- `textContent`: 与 `innerText` 类似，但性能更好

## 三、前端框架 (12-15)

### 12. Vue 组件中 data 为什么是函数？

**高频公司**: 京东、美团  
**参考答案**:

- 确保每个组件实例拥有独立的数据副本
- 如果是对象，多个实例会共享同一个引用，导致数据污染

### 13. Vue/React 虚拟 DOM 原理

**高频公司**: 字节跳动、阿里  
**考察点**:

- 虚拟 DOM 是 JS 对象对真实 DOM 的描述
- Diff 算法对比新旧虚拟 DOM，计算最小更新
- 批量更新真实 DOM，减少重排重绘

- 跨层级: Context API, Redux, Zustand
