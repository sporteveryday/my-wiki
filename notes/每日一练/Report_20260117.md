# 2026-01-17 大厂前端高频面试题 Top 30

## 一、JavaScript 核心基础 (1-10)

### 1. 事件循环 (Event Loop) 深度解析

**高频公司**: 字节跳动、腾讯、美团  
**考察点**:

- 宏任务 (Macrotasks) 与微任务 (Microtasks) 的执行优先级。
- `Promise.then`、`setTimeout`、`async/await` 的组合输出判定。

**参考答案**:

```javascript
console.log("start");
setTimeout(() => console.log("timeout"), 0);
Promise.resolve().then(() => console.log("promise"));
console.log("end");
// 输出: start -> end -> promise -> timeout
```

---

### 2. 原型与原型链及其继承实现

**高频公司**: 阿里巴巴、小米、字节跳动  
**考察点**:

- `__proto__` 与 `prototype` 的关系。
- 寄生组合继承的优缺点及 ES6 `class` 的实现本质。

**参考答案**:
原型链查找止于 `Object.prototype.__proto__ === null`。ES6 `extends` 底层依然通过原型链实现，但增加了对静态属性的继承。

---

### 3. 闭包 (Closure) 应用与内存泄漏

**高频公司**: 腾讯、网易、字节跳动  
**考察点**:

- 如何通过闭包实现私有变量。
- 循环引用导致的内存泄漏及如何处理。

**参考答案**:

```javascript
function counter() {
  let count = 0;
  return () => ++count;
}
```

使用完后将引用设为 `null` 可释放内存。

---

### 4. `this` 指向全场景判定

**高频公司**: 全部  
**考察点**:

- 箭头函数不绑定 `this`。
- `call/apply/bind` 显式绑定的区别。

**参考答案**:
优先级：`new` 绑定 > 显式绑定 > 隐式绑定 > 默认绑定。

---

### 5. Promise 及其静态方法源码实现

**高频公司**: 京东、小米、滴滴  
**参考答案**:
| 方法 | 特点 |
|------|------|
| all | 全部成功才返回成功，任一失败即返回失败 |
| allSettled | 无论成功失败，所有完成后返回结果数组 |
| race | 返回第一个完成的结果（无论成败） |

---

### 6. JS 精准数据类型判断

**高频公司**: 拼多多、京东  
**参考答案**:
`Object.prototype.toString.call(value).slice(8, -1).toLowerCase()` 是目前最兼容且精准的方式。

---

### 7. 浮点数精度丢失 (0.1+0.2 !== 0.3)

**高频公司**: 字节跳动、小米  
**参考答案**:
原因在于 IEEE 754 标准的二进制转换。解决方案：`Number.EPSILON`。

---

### 8. V8 引擎垃圾回收 (GC) 机制

**高频公司**: 腾讯、百度  
**考察点**:

- 分代回收：新生代（Scavenge）与老生代（Mark-Sweep）。

---

### 9. 显式绑定 `call/apply/bind` 手写

**高频公司**: 字节跳动、阿里  
**参考答案**:
`call` 与 `apply` 特点是立即执行，`bind` 返回新函数。手写时需注意原型绑定。

---

### 10. ES6 Proxy 及其应用场景

**高频公司**: 小米、字节跳动  
**参考答案**:
Vue3 响应式核心。相比 `defineProperty`，它支持数组下标监听和深层嵌套性能优化。

## 二、HTML 与 CSS (11-17)

### 11. CSS 盒模型及其计算差异

**高频公司**: 通用  
**参考答案**:
`border-box` 宽度包含 padding 和 border，相比 `content-box` 更符合布局直觉。

---

### 12. BFC (块级格式化上下文)

**高频公司**: 拼多多、美团  
**参考答案**:
触发条件：`overflow: hidden`, `float`, `absolute`。作用：清除浮动、解决 margin 重叠。

---

### 13. Flexbox 布局核心属性

**高频公司**: 小米、字节跳动  
**参考答案**:
`flex: 1` = `flex-grow: 1; flex-shrink: 1; flex-basis: 0%;`。

---

### 14. 页面水平垂直居中的多种方法

**高频公司**: 全部  
**参考答案**:

1. Flex: `justify-content: center; align-items: center;`
2. Grid: `place-items: center;`
3. Transform: `top: 50%; left: 50%; transform: translate(-50%, -50%);`

---

### 15. CSS 动画性能优化

**高频公司**: 字节跳动、阿里  
**参考答案**:
优先使用 `transform` 和 `opacity`。避免修改 `width`/`height` 导致的回流。

---

### 16. 响应式布局自适应方案

**高频公司**: 通用  
**参考答案**:
`vw/vh` 方案结合 `rem` (rem 取决于 root fontSize) 可实现精细适配。

---

### 17. HTML 语义化与 SEO

**高频公司**: 百度、网易  
**参考答案**:
使用 `<main>`, `<article>` 等标签不仅利于爬虫，也增强了屏幕阅读器的辅助功能。

---

## 三、浏览器原理与网络 (18-23)

### 18. 输入 URL 到页面显示全过程

**高频公司**: 全部  
**参考答案**:
DNS -> TCP (3次握手) -> TLS -> HTTP 发送 -> 接收 html -> 构建 DOM -> 构建 CSSOM -> Render Tree -> Layout -> Paint.

---

### 19. HTTP/1.1 与 HTTP/2 的核心区别

**高频公司**: 字节跳动、美团  
**参考答案**:
多路复用（解决队头阻塞）、头部压缩 (HPACK)、服务端推送。

---

### 20. 跨域 (CORS) 产生的根本原因

**高频公司**: 全部  
**参考答案**:
同源策略。CORS 通过 `Access-Control-Allow-Origin` 头进行松绑。

---

### 21. 浏览器强缓存与协商缓存对比

**高频公司**: 全部  
**参考答案**:
强缓存 (`Cache-Control`) 不向服务器发请求；协商缓存 (`ETag`) 会询问服务器内容是否更新。

---

### 22. Web 安全缺陷 (XSS, CSRF) 防御

**高频公司**: 阿里、腾讯  
**参考答案**:
XSS: 输入过滤 + CSP。CSRF: 同源验证 + CSRF Token。

---

### 23. WebSocket 连接握手过程

**高频公司**: 滴滴、快手  
**参考答案**:
基于 HTTP 的 `Upgrade: websocket` 协议升级。

---

## 四、框架原理与工程化 (24-27)

### 24. Vue2 与 Vue3 响应式底层差异

**高频公司**: 小米、美团  
**参考答案**:
Vue2 使用 `Object.defineProperty` (无法监控新增属性)；Vue3 使用 `Proxy` (全面代理)。

---

### 25. React Hooks 原理与闭包陷阱

**高频公司**: 字节跳动、腾讯  
**参考答案**:
Hooks 依赖数组存储状态。在 `useEffect` 或 `useCallback` 中需正确声明依赖项以避免闭包陷阱。

---

### 26. 虚拟 DOM 及 Diff 算法核心复杂度

**高频公司**: 阿里、京东  
**参考答案**:
通过树的分层对比及 key 值的标识，将复杂度从 O(n^3) 降为 O(n)。

---

### 27. Webpack 与 Vite 优化策略对比

**高频公司**: 小米、字节跳动  
**参考答案**:
Webpack 基于 Bundle，Vite 基于 Native ESM。Vite 开发环境热更新速度极快。

---

## 五、项目实战与场景题 (28-30)

### 28. Token 过期无感刷新方案

**高频公司**: 字节跳动  
**参考答案**:
在拦截器中捕获 401，利用 `refresh_token` 重写发起请求并同步更新。

---

### 29. 海量数据虚拟列表 (Virtual List) 实现

**高频公司**: 字节跳动、拼多多  
**参考答案**:
只渲染可视区。核心在于动态计算 `startIndex` 和 `endIndex`。

---

### 30. 前端错误监控采集方案

**高频公司**: 百度、腾讯  
**参考答案**:
`error` 事件 + `unhandledrejection`。Sentry 等 SDK 利用 source-map 还原源码。
