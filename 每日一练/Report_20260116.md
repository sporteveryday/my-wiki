## 详细答案解析 (精选)

### 1. 闭包 (Closure)

- **概念**：闭包是一个函数以及其捆绑的周边状态（词法环境）的引用。
- **场景**：模块化、模拟私有变量、柯里化。
- **内存泄漏**：未被清理的引用。解决方法：将不再需要的引用设为 `null`。

### 4. 事件循环 (Event Loop)

- **顺序**：同步代码 -> 微任务 (Promise.then, MutationObserver) -> 宏任务 (setTimeout, setInterval, I/O)。
- **注意**：每个宏任务执行完后，都会清空整个微任务队列。

### 16. HTTP 缓存

- **强制缓存**：`Cache-Control` (max-age), `Expires`。
- **协商缓存**：`Last-Modified/If-Modified-Since`, `ETag/If-None-Match`。
- **对比**：ETag 优先级更高，因为更精确。

### 19. 虚拟列表

- **核心**：只渲染可是区域的 DOM，非可视区域用 padding 或绝对定位撑开。
- **优化**：使用 `requestAnimationFrame` 保证平滑。
